# 封城十四天

> 14 天封控中的家庭抉择 · 一段关于柴米油盐、网课与深夜热粥的故事
> 使用 [Godot 4.7](https://godotengine.org/) 制作的剧情选择卡牌游戏

深夜，小区突然封控。十四天，一家四口困在房子里：妻子的账本、女儿的胃口、小儿子的线上测试、楼道里若隐若现的鱼汤香。作为一家之主，每一天你都要翻开一张牌，替这个家做出选择——而每一个选择，都在悄悄改写家的模样。

## 玩法

共 **14 天**。每天翻开一张事件牌，牌上是一个家庭场景与两个备选方案：

- 拖动卡牌 **左滑**，选择左侧方案；**右滑**，选择右侧方案
- 每个方案都会带来一段专属剧情，并改变家庭的**四维状态**
- 状态会在顶部实时跳动，卡面也会提前标出两个方案的效果
- 有些选择会埋下伏笔，有些事件要满足条件才会出现；14 天结束，游戏根据最终四维给出结算

## 操作方式

| 输入 | 动作 |
| --- | --- |
| 拖拽卡片左滑 / 右滑 | 选择左侧 / 右侧方案 |
| `←` 或 `A` | 选择左侧方案 |
| `→` 或 `D` | 选择右侧方案 |
| 点击底部按钮 | 与左右键等效 |
| `R`（结算后） | 重新开始 |

支持鼠标与触屏拖动。

## 四维状态

| 属性 | 说明 |
| --- | --- |
| 心情 `mood` | 全家人的情绪状态 |
| 免疫力 `immunity` | 身体在封控中的抵抗力 |
| 物资 `supplies` | 家里的粮油米面储备 |
| 和睦 `harmony` | 家人之间的关系与默契 |

初始四维为 **心情 60 · 免疫力 62 · 物资 56 · 和睦 65**，每项取值 0–100，会随选择增减并封顶保底。

## 事件与伏笔系统

- **条件触发**：部分事件带有 `req`（旗标或属性门槛），满足条件才会进入牌堆，例如"蛋糕"需要家里还有鸡蛋、"求助"会在物资与和睦跌到阈值后出现不同剧情
- **伏笔旗标**：`eggs`（家里有鸡蛋）、`crisis`（小儿子学业危机）、`talked`（是否与儿子谈过心）
- **隐藏分支**：某些方案的 `alt` 会在特定旗标成立时替换效果与结局文本（比如先谈心再处理成绩风波，结局完全不同）
- **加权抽取**：事件按权重随机抽取，且不会与上一天重复

## 运行方法

需要 [Godot 4.7](https://godotengine.org/)（本项目为纯 GDScript，无需 .NET 版本）。

1. 安装 Godot 4.7 稳定版
2. 打开 Godot，点击「导入」选择本项目目录，或直接用 Godot 打开根目录的 `project.godot`
3. 打开后首次会导入项目内自带的字体，稍等片刻即可
4. 按 `F5`（或点击右上角运行）开始游戏

设计分辨率为 720×1080，窗口默认 640×960，可自由缩放；已开启模拟触屏，鼠标拖拽即模拟手指滑动。

## 项目结构

```
Card/
├── project.godot            # 项目配置（主场景、窗口、渲染、触屏）
├── icon.svg                 # 项目图标
├── scenes/
│   └── Main.tscn            # 主场景
├── scripts/
│   ├── GameData.gd          # 全部事件数据 + 抽取 / 条件 / 隐藏分支逻辑
│   ├── Main.gd              # 主流程：天数循环、决策、结算与重开
│   ├── CardView.gd          # 卡牌视图：堆叠、拖拽、回弹与飞出
│   ├── StatBar.gd           # 四维属性条
│   ├── StatIcon.gd          # 属性图标
│   ├── SparkIcon.gd         # 装饰性四芒星图标
│   ├── Ui.gd                # UI 构建与样式工具
│   └── Fonts.gd             # 字体加载（带系统字体回退）
├── art/                     # 事件插图（png + 导入元数据）
└── fonts/                   # Noto Sans SC / Noto Serif SC（思源黑体 / 思源宋体）
```

## 素材

- **字体**：Noto Sans SC（黑体）与 Noto Serif SC（宋体），随项目打包在 `fonts/`，首次打开由编辑器自动导入；若导入异常会回退到系统字体
- **插图**：`art/` 下的事件配图（锁、谈心、蛋糕、鱼汤、账本等），围绕封控家庭的日常场景绘制
