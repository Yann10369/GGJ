# Grow · 封城之后

疫情背景下的家庭生存叙事卡牌游戏。玩家是一个四口之家的父亲，在家庭、邻里和社区责任之间做出选择。过去留下的决定，会改变后续事件和可用选项。

使用 Godot 4.7，入口为根目录 `Main.tscn`。在 Godot 中导入 `project.godot`，按 F5 运行。字体、插画和音效均使用项目内已有资源。

## 当前玩法

- 每天依次经历晨间信息、一次主动行动、最多两张事件、选择结果和夜间结算。
- 每个结果都由玩家点击继续；较长的卡面、结果、成长记录和结局可以滚动阅读。
- 当前可见选项恰好为两个时，使用左右滑动或方向键 / A、D 决策；卡下方常驻左右选项说明，不重复显示决策按钮。其余数量使用按钮或数字 1–4，禁止滑动。条件解锁改变选项数量时，交互方式也随之切换。
- 采购采用手机接龙界面，普通身份从 5 类选 3 类，志愿者从 7 类选 4 类。每次固定补充 10 物资，食物可补充免疫力，鸡蛋和热干面会留下食材计数。
- 成长记录只显示已发生的生活叙事，不透露隐藏变量、未发现的事件和结局条件。
- 结局先回顾旅程，再展示故事；结局页点击按钮或按 R 重开。

## 时间与规则

默认测试周期为 20 天，已取消标题对固定天数的依赖。`scripts/autoloads/GameManager.gd` 的 `story_days` 可调整；实际解封前夜不会早于已配置主线的最晚期限之后。如果主线在临近结束时又产生较晚的延迟后续，会为它顺延结局。它不会等待玩家已拒绝或条件不满足的路线无限循环。

心情 60、和睦 40、免疫力 70、物资 55，范围都是 0–100。和睦表示邻里与社区关系。夜间消耗 3 物资；整理物资后消耗 2；消息事件调整配给可以进一步减耗，最低为 1。结算后物资低于 25 时心情再减 1。隐藏暴露风险会影响身体疲劳和健康事件；休息与留在家中可以降低风险。

夜间依次判断免疫力、心情、物资归零结局，和睦归零不直接结束。平安走到解封前夜后，再根据家庭与社区关系判断结局。

事件池目前有 28 个模板。接龙固定在第 1、5、9、13、17 天，开场先出现封城。常规 A 位为社区 / 世界事件，B 位为家庭事件；接龙日 B 位可由到期的关键剧情或值守覆盖。关键事件采用期限保底，普通事件保留权重随机；值守每隔三天到期，与固定剧情冲突时保留到下一个可用卡位。

## 代码分工

- `Main.gd`：界面、输入、卡牌动画、成长记录入口，不维护第二份游戏状态。
- `scripts/core/GrowRun.gd`：唯一单局状态机，事件调度、种子、数值、采购校验、结局与回顾。
- `scripts/core/GameData.gd`：初始值、行动、条件规则、权重工具与结局文案。
- `scripts/core/EventLoader.gd`：按 `data/event_manifest.json` 加载 JSON，避免内联事件和配置不同步。
- `src/entities/card/Card.gd`：沿用的卡牌表现与拖动交互。
- `src/ui/menus/ShoppingCard.gd`：只展示当次采购候选并提交选择，奖励由单局状态机核算。
- `src/ui/hud/CommunityView.gd`：和睦驱动四档楼栋、灯光、邻居与配送车表现。

旧的拾荒阶段、人物资源及牌库骨架仍保留在目录中，但没有接入本作主流程。比赛版固定父亲主角，不包含拾荒倒计时、战斗、职业切换或构筑。

## 验证

用本机的 Godot 可执行文件替换下面的 `godot`：

```text
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/test_grow.gd
godot --headless --path . --script tests/test_ui.gd
```

规则测试覆盖完整单局、多种选择策略、延迟链、固定采购、三选项门槛、结局优先级、每日行动次数、重复提交和时间调整。界面测试实际实例化主场景并操作按钮，检查所有事件、多选采购、记录遮罩与重开。`tests/capture_ui.gd` 可在正常图形模式下保存界面截图到被忽略的 `tests/output/`。

当前存储的是本局内的记录，尚未加入退出续玩存档或跨周目收集。数值已用于流程验证，难度和 15–25 分钟目标时长仍需人工试玩确认。

事件配置见 `data/README.md`，实现说明见 `docs/COMPONENTS.md`。编剧原文保留在 `docs/events3.md` 和 `docs/endings.md`。
